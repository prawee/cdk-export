# CDK Export

Simple and demo to testing `Export` with `AWS Lambda` and `AWS CDK`.

## Prerequisites

- Node.js
- AWS CLI
- AWS CDK

## How to clone

```bash
git clone https://github.com/prawee/cdk-export.git
cd cdk-export
```

## How to run

```bash
npm install
npm run build
npx cdk synth
npx cdk deploy
```
